# Footer Copyright Design

## Goal

Add the company copyright notice supplied by the site owner to the bottom of the existing site footer.

## Content

Render the following text exactly as supplied, without adding a copyright symbol or changing the company name:

`2026 LIANGUANGIATEK LIMITED. All rights reserved.`

## Placement and presentation

- Keep the existing footer brand, tagline, and director/date lines unchanged.
- Add the copyright notice as the final line inside the existing footer container.
- Reuse the footer's existing centered, responsive layout.
- Style the notice as secondary footer information with a small, subdued treatment that remains readable on desktop and mobile.

## Verification

- Add a rendering test that locates the exact copyright text in the page footer.
- Run the complete automated test suite and production build before committing and pushing the implementation.

## Scope

This change adds only the copyright line. It does not alter company contact details, booking behavior, page content, or deployment configuration.
